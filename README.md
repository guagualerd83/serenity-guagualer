# Serenity Research — Public Beta

A minimal public dashboard for browsing public market commentary and aggregated research notes.

## Public-only repository
Never commit private collector credentials or databases here.

Do **not** upload:
- `.env`
- `*.curl`
- `*.sqlite` / `*.db`
- API keys, cookies, Discord webhooks

## Deploy
This repository is static HTML/CSS/JS and can be deployed directly with Cloudflare Pages.

## Data
Replace `data/dashboard.json` with sanitized exports generated by your private collector.
